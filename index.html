Sistema Médico

Aplicación web para administrar un consultorio médico: pacientes, doctores, citas, atenciones, exámenes y medicamentos.

Problema: centralizar la información clínica y administrativa que suele llevarse en papel u hojas de cálculo dispersas.

  • Python
  • Django
  • PostgreSQL
  • Bootstrap
  • JavaScript

Características

  • Registro de pacientes, doctores, especialidades, empleados y cargos.
  • Agenda de citas médicas y horarios de atención.
  • Atenciones médicas con diagnósticos, exámenes solicitados, medicamentos y servicios adicionales.
  • Estadísticas y auditoría de las acciones de los usuarios.
  • Inicio de sesión y registro de usuarios.
Repositorio

Casa del Uniformado

Sistema de inventario y facturación para un local que vende uniformes de policía, tránsito, bomberos y guardias de seguridad.

Problema: controlar el stock de cada prenda por talla, color y sección, facturar con IVA sin cálculos manuales y llevar el registro de clientes que deben.

  • Python
  • Django
  • PostgreSQL
  • JavaScript
  • GitHub Actions

Características

  • Inventario por variantes: producto, talla, color y sección.
  • Facturación con carrito, búsqueda dinámica (fetch/AJAX) y cálculo del IVA guardado por línea de venta.
  • Módulo de deudores con registro de abonos.
  • Facturas de proveedores para registrar compras.
  • Alerta diaria de reposición de stock por correo, programada con GitHub Actions.
Repositorio

Barbería Joseph Style

Sistema de gestión para una barbería: inventario, venta de servicios y productos, clientes con cartilla de fidelidad y colaboradores.

Problema: llevar el control de ventas, stock y cortes por barbero, y premiar a los clientes frecuentes sin tarjetas de papel.

  • Python
  • Django
  • SQLite
  • JavaScript
  • CSS3

Características

  • Panel general con indicadores y gráfico de ventas de la semana calculados desde la base de datos.
  • Registro de ventas con varios servicios que actualiza automáticamente la cartilla de fidelidad del cliente.
  • Inventario con movimientos de entrada, salida y ajuste, y filtro por categoría.
  • Cartilla visual de sellos por cliente.
  • Cortes y ventas del día por colaborador.
  • Interfaz con barra lateral en escritorio y pestañas inferiores en móvil.
